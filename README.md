## Kurulum

1. `.env` dosyasını oluşturun:
```bash
cp .env.example .env
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Projeyi build edin:
```bash
npm run build
```

## Geliştirme

Build işlemi otomatik olarak başlatılır. Manuel olarak başlatmak isterseniz:
