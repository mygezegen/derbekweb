# Dernek Mobil Uygulama

React Native (Expo) ile geliştirilmiş dernek üye portalı mobil uygulaması.

## Kurulum

```bash
cd mobile
npm install
```

## Çalıştırma

```bash
# Expo Go ile geliştirme
npm start

# Android
npm run android

# iOS
npm run ios
```

## Özellikler

- Giriş / Kayıt / Şifre Sıfırlama
- Ana Sayfa (istatistikler, son duyurular, yaklaşan etkinlikler)
- Duyurular listesi ve detay
- Etkinlikler (yaklaşan/geçmiş/tümü), etkinliğe katılım
- Aidatlarım (ödeme durumu, özet)
- Galeri (fotoğraf galerisi, lightbox görüntüleyici)
- Profil (bilgi görüntüleme ve düzenleme, çıkış)

## Gereksinimler

- Node.js 18+
- Expo CLI: `npm install -g @expo/cli`
- iOS için Xcode veya Android için Android Studio
- veya Expo Go uygulaması (fiziksel cihazda test için)
